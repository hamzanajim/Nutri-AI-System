"This is an AI Nutrition Assistant. It should reduce decisions for the user by planning meals, managing food inventory, tracking nutrition, managing groceries, reminding the user, and adapting to their lifestyle."

The AI should always make decisions using:

- User profile
- Fitness goal
- Daily nutrition targets
- Health conditions
- Allergies
- Food intolerances
- Digestive issues
- Food preferences
- Current inventory
- Grocery routine
- Meal history
- Supplement schedule

1. AI MEAL PLANNING ENGINE
----------------------------------------------------

Create a real AI meal planner.

The user should have a button:

"Generate My Meal Plan"

The generated meals must be based on:

- Calories remaining
- Protein target
- Carbohydrate target
- Fat target
- Inventory
- Health profile
- Diet preferences
- Number of meals per day

Every generated meal must include:

- Meal name
- Meal time
- Ingredients
- Quantity of every ingredient
- Calories
- Protein
- Carbs
- Fat

Users can:

- Edit meal
- Delete meal
- Duplicate meal
- Regenerate only one meal
- Create manual meals

Whenever a meal changes, nutrition totals must automatically update.

----------------------------------------------------
2. SMART INVENTORY VALIDATION
----------------------------------------------------

Every ingredient used inside a meal must exist in inventory.

If an ingredient is missing:

Show:

"This ingredient is not available."

Offer:

- Replace with inventory alternative
- Add to Grocery List
- Add to Inventory

Never silently ignore missing ingredients.

----------------------------------------------------
3. AI INGREDIENT REPLACEMENT
----------------------------------------------------

If a planned ingredient is unavailable:

Example:

Chicken unavailable.

AI automatically searches inventory for another protein.

Possible replacements:

Turkey
Ground Beef
Fish
Eggs
Tofu

The replacement should stay as close as possible to the same nutrition target.

Explain the reason.

Example:

"Chicken is unavailable. Replaced with Ground Beef because it matches today's protein target."

----------------------------------------------------
4. SMART GROCERY INTELLIGENCE
----------------------------------------------------

The grocery list must become intelligent.

Instead of a manual checklist:

The AI should compare:

- Current inventory
- Planned meals
- User consumption
- Shopping schedule

Then calculate:

Current quantity

Required quantity

Amount to buy

Example:

Chicken Breast

Current:
500g

Required:
2kg

Buy:
1.5kg

Reason:

Needed for next week's meals.

Do this for every inventory item.

Also support:

- Weekly shopping
- Every 15 days
- Monthly
- Custom schedule

Before shopping day automatically prepare the grocery list.

----------------------------------------------------

Automatically reduce inventory quantities.

Example:

Chicken

2000g

1800g

Nutrition progress must also update automatically.

----------------------------------------------------

Every inventory item already has:

Fridge

Freezer

Pantry
